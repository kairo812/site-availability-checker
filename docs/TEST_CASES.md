# Таблица тестирования (Приложение А)

Тестовое окружение: Python 3.12.3, aiohttp 3.14.5, rich 15.0.0.

Тестирование состоит из двух частей:

1. **Автоматические тесты** (`python -m unittest discover -s tests -v`): 40 тестов, результат **40 из 40 пройдено**, время около 4 с. Интернет не нужен, сайты имитирует локальный сервер.
2. **Ручные сценарии** в работающем приложении (таблица ниже).

> ⚠️ Столбец «Фактический результат» заполнен по прогону автора проекта. Перед защитой повтори ручные сценарии на своём компьютере, сделай скриншоты и при отличиях поправь таблицу. Время ответа у тебя будет другим, это нормально. В среде автора часть доменов (например, google.com) не открывалась из-за ограничений сети, поэтому у тебя результаты по `sites.txt` будут лучше.

## Исправленные ошибки и ограничения

**Что учтено по ходу разработки:**

- Коды 401/403/429 раньше считались «недоступно», хотя сервер жив. Введена отдельная категория «ОГРАНИЧЕН».
- Путь к `history.json` был привязан к текущей папке терминала. Теперь файлы лежат рядом со скриптом.
- Квадратные скобки в адресе могли сломать вывод `rich` (воспринимались как разметка). Все адреса выводятся через `Text` (есть тест).
- Запись истории сделана атомарной: временный файл и `os.replace`, чтобы сбой не уничтожил данные.

**Ограничения программы:**

- Проверяется только ответ сервера, а не содержимое страницы и не срок действия SSL-сертификата.
- IPv6-адреса вида `[::1]` не поддерживаются.
- История в JSON подходит для тысяч записей, для больших объёмов лучше SQLite.
- Мониторинг по расписанию (раз в N минут) не реализован: приложение запускается вручную или планировщиком ОС.
